# Электрический кодовый замок на Atmega8

## Общее описание
Устройство, предназначенное для управления электромагнитным замком с помощью ввода кода. Используется матричная клавиатура 4x4 (0-9, A, B, C, Enter, *, #). На LCD дисплей выводится информация о корректности/некорректности пароля, введённый пароль (замаскированный с помощью *) и состояние замка (открыт/закрыт)

## Текущие наработки
Было выполнено схемотехническое моделирование и программирование МК в Proteus. После этого осуществлено топологическое моделирование (трассировка печатной платы) в Altium Designer. Разводка была произведена на двухслойной плате
